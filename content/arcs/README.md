# Learning arcs

Six arcs make up the Phase 1 education layer. Each arc is ~2 hours of adaptive content,
HK-anchored, persona-aware. Phase 1 ships Arc 1; Arcs 2-6 are placeholders.

| # | Arc | Status |
|---|---|---|
| 01 | Why an OPC in Hong Kong, Why Now | Drafted |
| 02 | Incorporating in HK | Outline |
| 03 | Running it | Outline |
| 04 | The agent stack | Outline |
| 05 | Risk, liability, insurance | Outline |
| 06 | Succession & exit | Outline |

Each arc's markdown file carries a YAML front matter block declaring objectives, prerequisites,
duration, artifacts produced, and the mastery-check format. The tutor reads the front matter to
plan the session and reads the body as the canonical content to compress or expand from.
