Companion to `../Paper2_JMIR_SeriousGames_Manuscript.docx` and
`../JMIR_SeriousGames_Submission_Guide.md`.

JMIR's model: **tables and figures live inside the manuscript text**
(they already do). Separate figure files are requested at/after
acceptance for production — this package has them ready, extracted from
the manuscript itself so the uploads match the embedded versions
pixel-for-pixel.

## Do not upload

- The IJKM-era files (`figures_submission/` TIFF zip, APA manuscript,
  anonymous version) — different journal, different conventions.
- `Game_Screenshot_Level1-5.png` individually — they are composited
  into figure2.png; uploading extras without callouts causes editorial
  queries.
