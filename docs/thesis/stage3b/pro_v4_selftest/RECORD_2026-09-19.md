## What this package IS and IS NOT (from its own README/VALIDATION)
- A RESEARCHER SELF-TEST build with participant release disabled.
- Offline: local rule policy turning the player's own post-run report
  (difficulty/feeling/reason) plus performance counts into an OPTIONAL
  next-practice proposal (easier/same/harder/support/variety/pause) and
  a practice focus; the player always chooses.
- Optional: an external model ("Jev" via TypeSafe API) answers two typed
  choice questions; local guards (confidence >= .55, harder needs
  prob >= .80 and upward evidence, tired/clarity reports block override)
  can reject it. No live Jev call has ever been made (no key).
- It does NOT train any model. README: "There are no invented RLCD
  training routines in this package; it calls an existing Jev model and
  does not train its weights." Describe it in the thesis as a
  feedback-conditioned practice-proposal policy with an optional
  external-judgment step — NOT as RLHF/RLCD.
- Failure mode GO only; fixed-course generator retained. It is NOT a
  conversion of the frozen Stage-3B study build and must never be pooled
  with it (README says the same; v4.1 uses a separate browser namespace).
