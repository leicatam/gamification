# Stage-3B pipeline demonstration — hard-labelled synthetic dataset

This directory contains a fully simulated, hard-labelled demonstration dataset for the
Stage-3B analysis pipeline. It is impossible to mistake for real study data by design:

- **Every filename** starts with `SYNTHETIC_`.
- **Every participant ID** is in the reserved synthetic range `SYN-P001`..`SYN-P040`
  (real build codes are `B` + 5 base-36 characters — the ranges cannot collide).
- **Every record** (each return file's JSON) carries `"synthetic": true` and
  `"generated": "2026-09-13 by simulation for pipeline demonstration"` as its first two fields.
- **Every return file's first line** is a plain-text synthetic banner, before the build's
  2-line return format.
- Every table in the analysis document is headed **SYNTHETIC DEMONSTRATION — NOT STUDY DATA**.

## What the data mirrors

The return files reproduce the deployed-candidate build's text-message return format
(`Alpine_Coordination_Game_v3.0_Stage3B`) exactly, with only the synthetic markers added:
language-dependent header line (EN / 繁體 / 简体), then the entire export as ONE compact
single-line JSON string with the build's key order, JS number formatting (`0.5` not `0.50`,
`1` not `1.00`), `device_id: null`, `Lives_Lost` always 0, `Reached_GameOver` always `"FALSE"`,
`Post_FRA_Index` always `""`, string-keyed `state_logs` (`"1"`, `"2"`, ...), and the verbatim
init/rules/bump reason strings (arm A: `run start — arm A (adaptive, gentle floor)`, 6-second
rule-agent evaluations stepping difficulty from 0.60; arm B: `run start — arm B (static ×0.85)`,
fixed ×0.85, no rule evaluations). Scoring follows the pre-Amendment-A build:
`coins×10 + round(dist) + 50 goal bonus`, no penalties.

## Simulated population and PLANTED (known) effects

- N = 40, silent 50/50 arm split: 20 adaptive (A) / 20 static (B).
- Age bands 25-44 / 45-64 / 65-80, weighted to 65-80 (realised 4 / 10 / 26).
- Primary endpoint generative truth: P(D2 top-two-box) = **0.65 adaptive vs 0.45 static**
  (planted difference +20 points), sampled with realistic noise (seed 20260913).
- Behavioural truth: sessions/participant drawn with mean ≈ 3.6 (A) vs ≈ 2.7 (B).
- Planted missing data for the missing-data-handling demo: 3 participants with no
  questionnaire (SYN-P001, SYN-P002, SYN-P008), 3 participants with an early-ended run
  ("ended early by staff": SYN-P003, SYN-P008, SYN-P009); SYN-P008 is a dropout pattern
  (single sub-goal early run, no questionnaire).
- Realised primary result recovered by the pipeline: A 12/19 (63.2%) vs B 8/18 (44.4%),
  difference +18.7 points, 95% CI [−12.4, +45.3] (Newcombe), Fisher exact p = 0.33 —
  see `SYNTHETIC_demo_analysis.md`.

Everything above is a property of the simulation. Nothing in this directory says anything
about the real study (thesis rule G.8).

## Reproducibility

`python3 SYNTHETIC_generate.py` regenerates the entire dataset byte-identically
(deterministic seed 20260913). `python3 SYNTHETIC_verify.py` re-runs the integrity checks.
