# Stage-3B clean run — the simplified, zero-paperwork system

Distributors fill in NOTHING. The game and the phone record everything
automatically. You keep one short private list. That is the whole
system.

## How it works

Each distributor gets their OWN tagged copy of the frozen game
(Alpine3B_D01, D02, ... D20). The tag is baked into the file, so every
result that copy produces already says which distributor it came from
(the `device_id` field = D01, D02, ...). Nobody has to write it down.

- The game records automatically: frozen build stamp, consent +
  timestamp, anonymous participant code, age band and enrolment, full
  play data.
- The phone records automatically: when a distributor forwards the
  result from their own WeChat or e-mail, their account IS the
  independent-sender proof. No form needed.
- So each return already carries all three provenance facts on its own:
  (1) it is the frozen study build, (2) which distributor's copy
  (device tag), (3) an independent forwarder (the sending account).

## What each person actually does

- **Distributor:** help people play the copy you were given; when the
  game shows "Send results," forward it to
  sidney.tam@connect.polyu.hk from your own WeChat or e-mail. That's
  all. No names, no forms.
- **Participant:** just play. No e-mail, no account, no device of their
  own required — they can play on the distributor's phone.
- **You (researcher):** keep ONE private list, once — which tag went to
  whom (D01 = ..., D02 = ...). Your own working file; it never goes in
  the thesis archive (the archive uses only the D-tags). As results
  arrive, the device tag tells you which distributor each came through,
  automatically.

## Why this satisfies the provenance requirement without paperwork

The one thing to avoid is every return coming only from YOU with no
independent person in the chain. Here, each return is forwarded by an
independent distributor from their own account, and its device tag maps
to that distributor via your private list — so the chain of custody is
automatic and verifiable, with zero forms for anyone in the field.

The optional per-session log sheet is retired for normal use; use it
only for a supervised group session where you want session-level notes.
