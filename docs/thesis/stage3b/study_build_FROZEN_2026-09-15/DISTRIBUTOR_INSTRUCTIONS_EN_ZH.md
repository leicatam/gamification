# Stage-3B game — how to distribute and return results
# 滑雪协调游戏研究 — 派发与回传结果说明

**Use ONLY the file dated 2026-09-15 (name contains
`FROZEN_2026-09-15`). Please delete any earlier copy of the game.**
**请只使用文件名含 `FROZEN_2026-09-15`(2026年9月15日)的版本;**
**请删除任何较早版本的游戏文件,以免混用。**

Window / 研究期:15 September – 15 October 2026 / 2026年9月15日至10月15日。

---

## For the distributor / 给派发者

1. You have one tagged copy (DEV1–DEV5). Send YOUR copy to your
   contacts. Keep using the same copy so we can tell which group a
   result came from.
   您手上是其中一个编号版本(DEV1–DEV5)。请把您这一份发给您的联系人,
   全程使用同一份文件,方便我们分辨结果来自哪一组。
2. Each person opens the file on their own phone or computer. If two
   people must share one device, the second person should open it in a
   **private / incognito window** so a fresh game starts.
   每位参加者在自己的手机或电脑上打开文件。若两人共用一部设备,第二位请用
   **无痕/隐私窗口**打开,以便重新开始一局新游戏。
3. No names. Do not write the player's name anywhere — the game's own
   code identifies each record.
   请勿填写姓名。不要在任何地方写参加者的名字 — 游戏内部代码已能识别每份记录。

## For the player / 给参加者

1. Open the file. Tap **"I agree / 我同意"** on the consent page if you
   wish to take part (voluntary, anonymous, free).
   打开文件。若愿意参加,在同意页点击 **"我同意"**(自愿、匿名、免费)。
2. Fill the short enrolment (age band, etc.), then play. Each round is
   about 30 seconds; please play a few rounds.
   填写简短资料(年龄段等),然后游戏。每局约30秒,请玩几局。
3. At the end, answer the **4 short questions**.
   结束后,回答**4道简短问题**。
4. Press the **"Send results / 传送结果"** button. It opens an email to
   `sidney.tam@connect.polyu.hk`. **Send it exactly as it is — do not
   edit the content.** If the button does not open your email, use the
   **Save / 保存** option and email the saved file to the same address.
   按 **"传送结果"** 按钮,会打开一封发往
   `sidney.tam@connect.polyu.hk` 的邮件。**请原封不动发送,勿修改内容。**
   若按钮无法打开邮件,请用 **"保存"** 选项,把保存的文件邮寄到同一地址。

## Two versions of the game — please note / 请注意两种玩法

The game randomly gives each player one of two styles — some see a
"keep going" style, some see a "game over" style. This is by design;
players do not choose, and both are correct. Just play normally.
游戏会随机给每位参加者两种风格之一 —— 有人是"继续前进"风格,有人是"结束重来"
风格。这是设计安排,参加者无法选择,两者都正确。照常游戏即可。
