# 帮助者小卡片 / Helper card (Option B — open in browser)

The elderly participant only PLAYS and answers 4 questions aloud.
The helper does everything else, and opens the game in a browser ONCE.

═══════════════════════════════
【给帮助者 · 一次学会】
═══════════════════════════════

★ 关键一步:游戏不能在微信/WhatsApp 里直接玩,要用浏览器打开。★

准备(每部手机只做一次):
在微信/WhatsApp 里点开收到的游戏文件 →
 • 苹果(iPhone):点右上角「···」→「用其他应用打开」→ 选「Safari」。
   (若没有:「···」→「存储到文件」,再到「文件」App 点开 → 用 Safari 打开。)
 • 安卓(Android):点右上角「···」→「在浏览器打开」(选 Chrome 或系统浏览器)。
游戏在浏览器打开后,不要关掉这个页面 —— 一位接一位都用它。

每位长者(约 2 分钟):
1. 你点「我同意——开始玩」,帮长者选年龄段等。
2. 把手机递给长者玩滑雪游戏 —— 约 30 秒,玩两三局。
3. 结束后,你读出 4 条问题,按长者口头回答帮他点选。
4. 点「📤 分享我的结果」→ 选「微信」→ 发给研究员(或发给自己再转发)。
5. 点「🔄 下一位玩家」,就可以给下一位长者玩(不用重新打开文件)。

长者不需要懂手机 —— 只需玩游戏、回答问题。
请勿写姓名;游戏里的代码已能识别每份记录。
全程用发给你的同一份游戏,勿用旧版本。

═══════════════════════════════
[For the helper — learn once]
═══════════════════════════════

★ KEY STEP: the game will NOT run inside WeChat/WhatsApp. Open it in a
real browser. ★

Set up once per phone: in WeChat/WhatsApp tap the game file, then the
"..." menu ->
 • iPhone: "Open in other app" -> Safari (or "Save to Files", then open
   it from the Files app with Safari).
 • Android: "Open in browser" (Chrome or the system browser).
Once it opens in the browser, keep that page open — use it for everyone.

Per elder (~2 min): tap "I agree — start" and set the age band; hand
the phone to the elder to play the skiing game (~30s, 2-3 rounds); read
the 4 questions and tap their spoken answers; tap "Share my results"
-> WeChat -> send to the researcher; then tap "Reset for next player".

The elder never touches the menus. No names. Same game file throughout.
