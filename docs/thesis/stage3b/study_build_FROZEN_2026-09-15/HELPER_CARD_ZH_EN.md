# 帮助者小卡片 / Helper card — the elderly person does NOT touch the phone menus

The elderly participant only PLAYS the game and answers 4 questions
aloud. The helper does everything else. Give this card to helpers only;
participants need no instructions.

═══════════════════════════════
【给帮助者 · 一次学会】
═══════════════════════════════

准备(每位帮助者只做一次):
用你自己的手机,把游戏文件在浏览器打开。
• 苹果(iPhone):在「文件」App 点开该文件 → 用 Safari 打开。
• 安卓(Android):用浏览器(Chrome 或系统浏览器)打开。
打开后可选「添加到主屏幕」,以后一点图标即开,不用再找文件。

每位长者(约 2 分钟):
1. 你点「我同意——开始玩」,帮长者选年龄段等。
2. 把手机递给长者,让他玩滑雪游戏 —— 约 30 秒,玩两三局。
3. 游戏结束后,你读出 4 条问题,按长者口头回答帮他点选。
4. 点「📤 分享我的结果」→ 选「微信」→ 发给研究员;
   或发给你自己,再用微信原样转发。

长者不需要懂手机 —— 只需玩游戏、回答问题。
请勿写姓名;游戏里的代码已能识别每份记录。
全程用发给你的同一份游戏,勿用旧版本。

═══════════════════════════════
[For the helper — learn once]
═══════════════════════════════

Set up once (per helper): open the game file in your phone's browser
(iPhone: open it in the Files app → open with Safari; Android: open
with a browser). Optionally "Add to Home Screen" for one-tap access.

For each elder (~2 min): you tap "I agree — start", set the age band,
hand them the phone to play the skiing game (~30s, two or three
rounds), then read the 4 questions and tap their spoken answers.
Finally tap "Share my results" → choose WeChat → send to the
researcher (or to yourself, then forward).

The elder never touches the menus. No names. Same game file throughout.
