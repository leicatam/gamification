Research instrument for the Stage 3 decoupling study (coordination-game framing), short-run build: a run ends when the distance goal (200 m or 400 m) is reached or at the 20-second cap — whichever comes first. Controls: USB joystick or foot pad via the browser Gamepad API (left/right axis or D-pad), or keyboard arrows. All telemetry stays in this browser until you export it. The agentic mode calls the Claude API with aggregate game parameters only; if the call fails or times out, the built-in rule agent takes over — the same fail-safe as the Phase 1 five-layer architecture. Exported CSV columns match the Stage 3 logbook "Game Telemetry" sheet.
