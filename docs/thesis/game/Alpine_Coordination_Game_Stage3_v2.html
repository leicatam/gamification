Research instrument for the Stage 3 decoupling study (coordination-game framing), short-run build: a run ends when the distance goal is reached or at the time cap — 30 s for the 200 m run, 60 s for the 400 m run — whichever comes first. In zero-failure mode a bump never slows the player; it clears obstacles ahead and eases the slope instead. All sound is synthesized in the browser (toggle with the 🔊 button). Controls: USB joystick or foot pad via the browser Gamepad API (left/right axis or D-pad), or keyboard arrows. All telemetry stays in this browser until you export it. The agentic mode calls the Claude API with aggregate game parameters only; if the call fails or times out, the built-in rule agent takes over — the same fail-safe as the Phase 1 five-layer architecture. Exported CSV columns match the Stage 3 logbook "Game Telemetry" sheet.
